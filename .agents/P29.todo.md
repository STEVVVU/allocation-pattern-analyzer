## Definition of done

The exact installed angr 9.2.207 analyzes an owned ELF x86-64 fixture through a CLI with symbol and bound validation. Output separates syntactic candidates, feasible witnesses, and unresolved cases. Seed-first exploration compares all three strategies under common configured bounds and records blocks, solver calls, witness validity, and limits. Launch, Doctor, Drive, Evidence, and Cleanup pass on a mapped feature, and the evidence survives cleanup. Pinned Ubuntu CI repeats the journey on Linux; its native proof requires a hosted workflow run.

## Scope and blockers

The task adds analyzer CLI modes, two exploration strategies, controlled C fixtures, a verifier, documentation, and one read-only Linux workflow. The full angr checkout is retained as provenance, and the local angr wheel was built from the exact released source distribution. The hosted workflow downloads and statically scans official Linux 6.6 source built as `vmlinux`; it never boots the kernel. Windows clang and lld can generate ELF files, but Windows cannot execute them natively; native witness proof depends on hosted Ubuntu. No host kernel, cloud service, or deployed target is accessed.
